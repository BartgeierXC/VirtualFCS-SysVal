# VirtualFCS-SysVal

Modelica library for the system-level simulation of a PEM fuel cell system on a testbench. It is the model of the accompanying publication. The measurement data and the simulation results of the publication are published in the Zenodo record [10.5281/zenodo.24310446](https://doi.org/10.5281/zenodo.24310446), the evaluation code is [FCSysVal](https://github.com/BartgeierXC/FCSysVal).

VirtualFCS-SysVal 2.1.0-sysval is based on the development state 2.1.0-dev of the open-source Modelica library VirtualFCS after its release v2.0.0 (MIT license, Copyright (c) 2021 Virtual-FCS H2020), extended for the PEM fuel cell system of the publication. It is not an official VirtualFCS release. The Modelica top-level package keeps the name VirtualFCS and the version annotation 2.1.0-dev, so OpenModelica offers the conversion script of VirtualFCS from 2.1.0-dev to v3.0.x for this version. The conversion has not been tested with the SysVal extensions.

This state contains the parameter set of the second iteration of the validation process (re-identified parameters). The parameter set of the first iteration is provided as the patch file `VirtualFCS-SysVal_iteration1.patch` in this repository. Apply it with `git apply VirtualFCS-SysVal_iteration1.patch` in the root folder of the repository.

The published model uses the default membrane parameters of Hahn (2023). The results of this publication were computed with confidential stack-specific values, so the published model does not reproduce the published cell voltages exactly. The Zenodo record therefore contains the original simulation results.

## Model description

The library models a PEM fuel cell system with the stack and its balance of plant: hydrogen supply with anode recirculation, air supply with compressor or mass flow controller, membrane humidifier and cathode pressure control valve, and the coolant loop with heat exchanger. The reference system simulation is `VirtualFCS.ComponentTesting.TestFuelCellSystem`.

### Library structure

- `Electrochemical`: PEM fuel cell stack, algebraic cell-voltage model and fuel cell system.
- `SubSystems`: hydrogen supply with anode recirculation, air supply (compressor or mass-flow controlled) and cooling loop variants.
- `Fluid` and `Thermal`: balance-of-plant components (membrane humidifier, map-based compressor and recirculation blower, coolant pump, flow resistances, valve characteristics, heat exchanger).
- `Utilities`: operating-point input (`SystemControl`), polynomial maps and helper functions.
- `ComponentTesting`: test models. `TestFuelCellSystem` is the reference system simulation.

### Operating-point input (OpCons)

Operating points are supplied as a Modelica text table named `op_cons` (`float op_cons(nrows, ncols)`, first column = time in s). By default the file `VirtualFCS/Resources/LuT/OpCons_data.txt` is used. This file is an interface: external software overwrites it, so its content and column layout change with the use case. The column layout must match the structure of the simulated model. For example, a compressor-based air subsystem needs a compressor speed, while a mass-flow-controlled one needs an air mass flow. A model can instead reference a dedicated file with the same table format (e.g. `OpCons_data_TestFuelCell.txt`) via its `fileName` parameter. The expected column layout of each model is given in its documentation. The input tables of the simulation runs in the Zenodo record are generated by its evaluation code.

## System requirements and installation

The library is designed to work with OpenModelica. This version was developed and tested with OpenModelica 1.26.1:

[Information about OpenModelica](https://www.openmodelica.org/)<br/>
[Download OpenModelica for Windows](https://openmodelica.org/download/download-windows/)<br/>
[OpenModelica on GitHub](https://github.com/OpenModelica)<br/>

To use the library:
1. Clone this repository.
2. Open the OpenModelica Connection Editor.
3. Open the file `VirtualFCS\package.mo`.
4. The library loads in the library browser on the left of the Connection Editor.

The library depends on the Modelica Standard Library 4.0.0 and the [Buildings library](https://github.com/lbl-srg/modelica-buildings) 10.0.0 (see the `uses` annotation in `VirtualFCS/package.mo`). Install Buildings 10.0.0 before loading the library, e.g. with the OpenModelica package manager.

## Conventions

Naming conventions of the code, inherited from VirtualFCS:

Classes. Classes should be nouns in UpperCamelCase (e.g. FuelCellStack).<br/>
Instance. Instance names should be nouns in lowerCamelCase. An underscore at the end of the name may be used to characterize an upper or lower index (e.g. automotiveStack, pin_a).<br/>
Method. Methods should be verbs in lowerCamelCase (e.g. updateFuelCellStack).<br/>
Variables. Local variables, instance variables, and class variables are also written either as single letters or in lowerCamelCase (e.g. U, cellVoltage).<br/>
Constants. Constants should be written in uppercase characters separated by underscores (e.g. T_REF).<br/>
